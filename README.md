# Value Rate Calculator

价值收益率计算器 —— 一个纯前端单文件网页工具。

输入两组数值（网站主/客队、对比平台主/客队），自动判断每组是"赔率"还是"奖励率"，计算胜率、公平赔率、价值与期望收益，并给出参考下注金额（100 的整数，范围 100–2000 元）。

## 在线使用

GitHub Pages 已部署，直接打开：

> https://angelky7.github.io/value-rate-calculator/

无需安装任何依赖，纯静态页面，所有计算均在浏览器本地完成，不上传任何数据。

## 功能

- **自动类型识别**：同一组的两个数值都 > 1 视为赔率，都 ≤ 1 视为奖励率，无需手动选择
- **胜率计算**：赔率 → 胜率 = 1/赔率；奖励率 → 胜率 = 直接使用
- **庄家优势去偏**：隐含概率总和 > 1 时自动归一化
- **公平赔率 / 价值 / 期望收益**：完整计算并区分正负
- **结论优先**：大字显示推荐结论与下注金额，详细数据折叠展示
- **下注建议**：强烈推荐 2000 元 / 谨慎推荐 100 元 / 不推荐 0 元（100 的整数）
- 快捷键 `Ctrl+Enter` 快速分析；内置示例数据一键填充

## 使用方法

1. 输入网站的主队 / 客队数值
2. 输入对比平台的主队 / 客队数值
3. 点击【开始分析】
4. 查看顶部结论卡与关键指标，需要时展开"查看详细计算过程"

## 计算规则

```
赔率     → 胜率 = 1 / 赔率
奖励率   → 胜率 = 奖励率
对比平台奖励率 → 赔率 = 奖励率 + 1
公平赔率 = 1 / 去偏后胜率
价值     = 实际赔率 / 公平赔率 − 1
期望收益 = 胜率 × 实际赔率 − 1
```

| 情形 | 结论 | 下注金额 |
|---|---|---|
| 价值 > 0 且期望 > 0 | 强烈推荐 | 2000 元 |
| 仅其中一项 > 0 | 谨慎推荐 | 100 元 |
| 均 ≤ 0 | 不推荐 | 0 元 |
